📖 4-Step Quick Setup Guide

1

Install Modern SSL Root Certificate

Open Safari on your iPad and tap isrgrootx1.crt to install the Let's Encrypt CA profile. This fixes HTTPS connections for Cydia and GitHub Pages on iOS 9.

2

Jailbreak & Install AppSync Unified

Run kok3shi9 or Phoenix on iOS 9.3.5. In Cydia, add https://cydia.akemi.ai/ and install AppSync Unified to permanently enable unsigned packages.

3

Add Source & Install NavigatoreOSM

In Cydia, tap Sources > Edit > Add, enter https://vibe-maribit.github.io/NavigatorOSM/, and install NavigatorOSM.

4

Mount in Vehicle & Tether GPS

Mount your iPad Mini horizontally, plug into a 12V 2.1A charger, and turn on your phone's Wi-Fi hotspot (iPhone passes GPS automatically; for Android run our companion GPSTether.apk).
